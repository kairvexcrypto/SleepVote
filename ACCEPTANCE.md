# Серверная приёмка

Статус: ещё не выполнена на живом Paper.

1. Чистый Paper 1.21.11 / Java 21, два игрока Survival. В настроенном мире проверить установку minecraft:players_sleeping_percentage = 101 и запись исходного значения в leases.
2. Установить ночь. При 50% один из двух игроков должен дать кворум. Утро наступает после заданного времени удержания, а не мгновенно.
3. Сон в кровати вместе с виртуальным голосом того же игрока не должен дать два голоса.
4. Отзыв виртуального голоса не должен отменять сон в кровати. Выход спящего игрока должен пересчитать кворум.
5. Creative, Spectator, dead, sleepingIgnored и sleepvote.exclude не входят в число участников.
6. В двух мирах голосования независимы. Переход между мирами удаляет старый виртуальный голос.
7. При потере кворума отсчёт сбрасывается. Новый игрок, вошедший во время отсчёта, меняет требуемое число голосов.
8. При успешном пропуске погода меняется только при clear-weather. Проверить сообщения и удаление bossbar.
9. Перезагрузка правил очищает голоса. Неверный YAML должен оставить прежние правила.
10. Штатное отключение восстанавливает исходное правило сна. После имитации аварийного завершения сохранённое исходное значение не должно стать 101.
11. Ручное изменение gamerule во время работы прекращает управление миром. Отключение не перезаписывает выбранное администратором значение.
12. Проверить загрузку/выгрузку миров, восстановление по UUID, ошибки записи и повреждённый leases.dat на копии данных.
13. Проверить взаимодействие с плагинами времени, сна и прав на конкретной серверной сборке. Если смена времени отменена, сообщение об успешном пропуске не должно появляться.

Записать точную сборку Paper и фактические результаты. Автоматические тесты ядра голосования не заменяют эту приёмку.
